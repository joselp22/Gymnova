# Documentación histórica

Los archivos de este directorio describen versiones anteriores del proyecto
GYMNOVA (base de 62 tablas, credenciales `Gymnova2026*`, usuario `admin`,
módulo Inventario, etc.). Se conservan solo como referencia de la
evolución del sistema.

Para la versión vigente, consultar:

- `../AUDITORIA_GYMNOVA.md` — auditoría técnica inicial (Fase 1).
- `../RESUMEN_ENTREGA_FINAL.md` — resumen operativo con las 35 tablas,
  credenciales actuales (`jose/Admin123*`, `Gymnova123*` para los 4 roles
  restantes), flujos guiados y guion de presentación.
- `../entrega/gymnova_db_entrega.sql` — dump SQL portable con IDENTITY
  y secuencias correctamente declaradas.

Cualquier procedimiento que aparezca en estos archivos históricos y que
mencione módulos como Inventario, tablas como `objetivo_fitness` u
`horario`, o contraseñas antiguas, **no aplica al sistema actual**.
